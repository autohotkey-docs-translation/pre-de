#Module [v2.1-alpha.11+]

Startet ein neues Modul oder öffnet ein existierendes Modul.

#Module ModulName

Parameter

ModulName

Ein eindeutiger Name, der für #Import verwendet wird.

[v2.1-alpha.21+]: Dies muss ein gültiger Identifikator sein. Jedes aus einer Datei importierte Modul besitzt einen eigenen Satz von Modulnamen, die unabhängig vom Hauptskript sind.

Bemerkungen

Das neue Modul startet mit einem leeren globalen Namensraum und impliziten Import aus dem internen Modul.

[v2.1-alpha.21+]: Das Modul endet bei der nächsten #Module-Direktive in der aktuellen Datei oder am Ende der aktuellen Datei.

[v2.1-alpha.21+]: Die #Module-Direktive erstellt ein untergeordnetes Modul bzw. Untermodul, das entweder mit der Hauptskriptdatei oder mit einer via #Import importierten Datei verlinkt ist. Module, die mit derselben Datei verlinkt sind, können sich gegenseitig via ModulName importieren, während andere Module Untermodule mithilfe eines pfadqualifizierten Namens im Format "Pfad:Modulname" importieren können. Der Name __Init kann verwendet werden, um das initiale Modul einer Gruppe zu importieren.

Module, die auf diese Weise definiert werden, haben Vorrang vor Modulen im Dateisystem, jedoch nur für genau den in der Direktive verwendeten ModulName.

[v2.1-alpha.20+]: Handelt es sich bei ModulName um AHK, __Main oder einen Namen, der bei einer vorherigen #Module-Direktive verwendet wurde, wird das existierende Modul "erneut geöffnet", was das Hinzufügen von Startcode und Definitionen ermöglicht.

[v2.1-alpha.21+]: Die Verwendung von #Module in einer Datei, die mehrfach via #Include geladen wird, ist nicht zulässig. Der Grund dafür ist, dass dadurch das Modul "erneut geöffnet" und sein Inhalt dupliziert werden würde, was häufig zu irreführenden Meldungen bezüglich doppelter Deklarationen führt. Beachten Sie, dass diese Restriktion nicht für mehrere Instanzen von #Include im selben Modul gilt, da die Datei in solchen Fällen nur einmal inkludiert wird.

#Module kann nicht innerhalb eines Blocks oder als Körper einer Kontrollanweisung verwendet werden.
