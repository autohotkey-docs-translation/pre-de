#Warn

Aktiviert oder deaktiviert bestimmte Warnungen, die auf mögliche Fehler vonseiten des Programmierers hinweisen, wie z.B. Schreibfehler oder fehlende "globale" Deklarationen.

#Warn WarnungTyp, WarnungModus

Parameter

WarnungTyp

Typ: Zeichenkette

[v2.1-alpha.12+]: Wenn weggelassen, wird der programmweite Standardwarnmodus geändert. Dies wird von allen Warnungstypen verwendet, die standardmäßig aktiv sind oder auf On gesetzt sind.

[v2.0]: Wenn weggelassen, wird standardmäßig All verwendet. Das Komma muss vorhanden sein.

Andernfalls geben Sie den Typ der Warnung an, die aktiviert oder deaktiviert werden soll.

VarUnset: Zeigt vor Beginn der Skriptausführung eine Warnung an, wenn die jeweils erste Referenz zu einer Variable nie auf eine der folgenden Arten verwendet wird:

  • Als Ziel einer direkten, nicht-dynamischen Zuweisung, z.B. MeineVar := "".
  • Mit dem Referenzoperator verwendet, z.B. &MeineVar.
  • Direkt an IsSet übergeben, z.B. IsSet(MeineVar).

LocalSameAsGlobal: Zeigt vor Beginn der Skriptausführung eine Warnung an, wenn undeklarierte lokale Variablen den gleichen Namen wie globale Variablen haben. Diese Warnung soll Fehler vermeiden, die auftreten können, wenn vergessen wurde, eine globale Variable innerhalb einer Funktion vor dem Zuweisungsversuch zu deklarieren. Wenn die globale Variable tatsächlich lokal sein soll, kann die Warnung mit einer Deklaration wie local x oder static y unterdrückt werden.

Diese Warnung ist standardmäßig deaktiviert.

#Warn
g := 1
ShowG() {       ; Die Warnung wird auch angezeigt, wenn die Funktion nicht aufgerufen wird.
    ;global g   ; <-- Dies wird für die Zuweisung an die globale Variable benötigt.
    g := 2
}
ShowG
MsgBox g        ; Ohne die Deklaration hat obiges einem lokalen "g" zugewiesen.

Unreachable: Zeigt vor Beginn der Skriptausführung eine Warnung an, wenn unmittelbar nach einem Return, Break, Continue, Throw oder Goto eine Zeile auf gleicher Verschachtelungsebene folgt, es sei denn, diese Zeile ist das Ziel eines Labels. Zeilen dieser Art werden niemals ausgeführt.

Wenn der Code nicht erreichbar sein soll – z.B. wenn ein return verwendet wurde, um einen Codeblock vorübergehend zu deaktivieren, oder wenn ein Hotkey oder Hotstring durch Auskommentieren vorübergehend deaktiviert wurde – sollten Sie in Erwägung ziehen, den nicht erreichbaren Code ebenfalls auszukommentieren. Sie können die Warnung auch unterdrücken, indem Sie ein Label über der ersten nicht erreichbaren Zeile definieren.

All: Wendet den angegebenen WarnungModus auf alle unterstützten Warnungstypen an.

WarnungModus

Typ: Zeichenkette

Wenn weggelassen, wird standardmäßig On verwendet. Andernfalls geben Sie einen Wert an, der festlegt, wie Warnungen übermittelt werden sollen.

MsgBox: Zeigt ein Mitteilungsfenster an, das die Warnung beschreibt. Beachten Sie, dass das Skript nach dem Schließen des Mitteilungsfensters normal weiterläuft.

StdOut: Sendet eine Beschreibung der Warnung zur Standardausgabe (stdout), inklusive Dateiname und Zeilennummer. Auf diese Weise können umfangreiche Texteditoren wie SciTE die Warnungen abfangen, ohne das Skript zu unterbrechen – der Benutzer kann später den Ausgabebereich des Texteditors verwenden, um zu einer fehlerhaften Zeile zu springen.

OutputDebug: Sendet eine Beschreibung der Warnung zum Debugger, um sie anzuzeigen. Wenn kein Debugger aktiv ist, hat dieser Modus keinen Effekt. Weitere Details finden Sie unter OutputDebug.

On [v2.1-alpha.12+]: Aktiviert den angegebenen WarnungTyp unter Verwendung des programmweiten Standardmodus, was standardmäßig MsgBox ist. Mit einem separaten #Warn WarnungModus kann der Standardmodus geändert werden.

Off: Deaktiviert alle Warnungen für den angegebenen WarnungTyp.

UTF-8 [v2.1-alpha.13+]

Es wird eine Warnung angezeigt, wenn eine als UTF-8 gelesene Skriptdatei ein oder mehrere Bytes enthält, die nicht Teil einer gültigen UTF-8-Byte-Sequenz sind. Diese Bytes können nicht in ein Zeichen dekodiert werden und werden daher mit '�' ersetzt. Dies deutet in der Regel darauf hin, dass die Skriptdatei nicht unter UTF-8 gespeichert wurde. Standardmäßig geht AutoHotkey davon aus, dass Dateien, die ASCII-fremde Zeichen enthalten, unter UTF-8 kodiert sind. Um das zu beheben, speichern Sie die Datei unter UTF-8 oder entfernen Sie alle ungültigen Byte-Sequenzen.

Diese Warnung verwendet den Standardausgabemodus, und kann nur deaktiviert werden, wenn der Standardmodus auf Off gesetzt wird.

Bemerkungen

Wenn diese Direktive im Skript nicht angegeben ist, sind alle Warnungen aktiviert und verwenden den MsgBox-Modus, mit Ausnahme der LocalSameAsGlobal-Warnung, die deaktiviert ist.

[v2.1-alpha.12+]: Jedes Modul hat seine eigenen Warneinstellungen. Module, die mit #Module definiert werden, verwenden standardmäßig dieselben Einstellungen wie das vorherige Modul. Beim Standardmodul und bei den via #Import geladenen Modulen sind VarUnset und Unreachable standardmäßig On, während LocalSameAsGlobal standardmäßig Off ist.

[v2.1-alpha.12+]: Ein programmweiter Standardmodus kann mit #Warn WarnungModus gesetzt werden, mit jedem Modus außer On. Die letzte einer solchen Direktive beeinflusst alle Warnungen, die standardmäßig aktiv sind, und alle Warnungen, bei denen WarnungModus auf On gesetzt wurde. #Warn Off führt dazu, dass solche Warnungen ignoriert werden. Außerdem gibt es folgende Sonderfälle:

  • #Warn: Aktiviert VarUnset und Unreachable und deaktiviert LocalSameAsGlobal für das aktuelle Modul.
  • #Warn On: Aktiviert VarUnset und Unreachable für das aktuelle Modul.

Die Überprüfungen, die VarUnset-, LocalSameAsGlobal- und Unreachable-Warnungen erzeugen, werden durchgeführt, nachdem alle Direktiven geparst wurden, aber bevor das Skript ausgeführt wird. Folglich ist die Position der Direktive innerhalb eines Moduls ohne Bedeutung (und kann wie alle anderen Direktiven nicht bedingt ausgeführt werden).

Die Anordnung der #Warn-Direktiven ist allerdings entscheidend, wenn WarnungTyp angegeben ist: die letzte Direktive, die eine bestimmte Warnung setzt, bestimmt den Modus dieser Warnung. Zum Beispiel haben die beiden unteren Direktiven den kombinierten Effekt, alle Warnungen außer LocalSameAsGlobal zu aktivieren (was auch die Standardkonfiguration ist):

#Warn All
#Warn LocalSameAsGlobal, Off

Beispiele

Deaktiviert alle Warnungen für das aktuelle Modul. Nicht empfohlen.

#Warn All, Off

Aktiviert alle Warnungstypen für das aktuelle Modul. [v2.1-alpha.12+]: Verwendet den programmweiten Standardmodus.

#Warn All

Für v2.1 werden damit lediglich die Standardwarnungen gesetzt, die mit dem programmweiten Standardmodus aktiviert werden sollen. Für v2.0 werden damit alle Warnungen aktiviert und der Modus auf MsgBox gesetzt.

#Warn

Sendet eine Warnung an OutputDebug für jede undeklarierte lokale Variable, die den gleichen Namen wie eine globale Variable hat.

#Warn LocalSameAsGlobal, OutputDebug

[v2.1-alpha.12+]: Bewirkt, dass Warnungen via StdOut übermittelt werden, es sei denn, für die Warnung wurde ein Modus angegeben.

#Warn StdOut
