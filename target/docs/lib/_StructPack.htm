#StructPack [v2.1-alpha.19+]

Setzt die maximale Ausrichtungsanforderung für nachfolgende typisierte Eigenschaften.

#StructPack Einstellung

Parameter

Einstellung

Typ: Integer

Wenn weggelassen oder 0, werden Ausrichtungsanforderungen auf Standard zurückgesetzt. Andernfalls geben Sie 1, 2, 4 oder 8 an, um eine maximale Anforderung für die aktuelle Klasse oder das aktuelle Modul zu setzen.

Bemerkungen

Der von dieser Direktive gesetzte Wert entspricht direkt dem Pack-Wert, der an DefineProp übergeben wird, wenn die Klasse initialisiert wird. Jedes Strukturfeld, das innerhalb einer Klassendefinition deklariert ist, verwendet den Pack-Wert, der von der jüngsten #StructPack-Direktive innerhalb der aktuellen Klasse, der umschließenden Klasse oder des Moduls gesetzt wurde.

Diese Direktive kann mehrmals innerhalb einer Klasse verwendet werden und beeinflusst nur die nachfolgenden Felder.

Die Ausrichtungsanforderung der Klasse selbst ist die ihres striktesten Mitglieds (das Feld mit der größten Ausrichtungsanforderung).

Strukturen

Beispiele

Deaktiviert das Padding in einer Strukturklasse.

class AB1 {
    #StructPack 1
    a : Int8
    b : Int32
}
class AB2 {
    a : Int8
    b : Int32
}
MsgBox "AB1: " AB1.Prototype.GetOwnPropDesc('b').Offset
MsgBox "AB2: " AB2.Prototype.GetOwnPropDesc('b').Offset
