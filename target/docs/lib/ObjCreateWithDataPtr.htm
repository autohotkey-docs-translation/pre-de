ObjCreateWithDataPtr [v2.1-alpha.36+]

Erstellt ein Objekt mit einem internen Datenpointer.

Obj := ObjCreateWithDataPtr(ClassObj, Adresse)

Parameter

ClassObj

Typ: Objekt

Ein Class-Objekt, das eine direkte Konstruktion unterstützt.

Adresse

Typ: Integer

Eine Zahl im nativen Integer-Bereich (32-Bit oder 64-Bit). Wenn ClassObj typisierte Eigenschaften definiert, muss der Wert entweder null oder eine kompatible Speicheradresse sein.

Rückgabewert

Typ: Objekt oder Struct

Der Rückgabewert ist ein von ClassObj.Prototype abgeleitetes Objekt.

Fehlerbehandlung

Es wird eine Ausnahme ausgelöst, wenn ClassObj nicht unterstützt wird.

Die Übergabe einer ungültigen Adresse ungleich null kann zu einer Instabilität des Programms führen, wenn ClassObj typisierte Eigenschaften definiert.

Bemerkungen

Ziehen Sie alle anderen Möglichkeiten in Betracht, bevor Sie diese Funktion nutzen. Sie ist für bestimmte Sonderfälle vorgesehen, wie zum Beispiel:

  • Beim Implementieren von Abstraktionen für Funktions-Pointer, Interface-Pointer, Handles und Ähnliches, wobei Obj selbst den Pointer- oder Handle-Wert repräsentiert – ähnlich einem gekapselten Pointer, jedoch mit aktiviertem __Delete.
  • Beim Erstellen eines Nicht-Struktur-Objekts, dessen typisierte Eigenschaften auf Speicher außerhalb des Objekts selbst verweisen.

Diese Funktion sollte nicht bloß dazu verwendet werden, eine überschriebene statische Call-Methode zu umgehen. Rufen Sie innerhalb der Methode super() oder super.Call() auf, um eine Instanz zu konstruieren. Man kann eine überschriebene Methode auch umgehen, indem man explizit ihre Superklassenversion aufruft, wie in (Object.Call)(ClassObj).

Anders als ClassObj.Call erstellt diese Funktion ein Objekt, ohne __Init oder __New aufzurufen; das Skript kann diese jedoch bei Bedarf manuell aufrufen. Wenn __Init nicht aufgerufen wird, werden Instanzvariableninitialisierer nicht ausgeführt. Das Endergebnis ähnelt einem Ausdruck wie {Base: ClassObj.Prototype}, außer dass ein breiteres Spektrum an Klassen unterstützt wird.

Anders als bei StructClass.At wird __Delete aufgerufen, wenn das Objekt gelöscht wird.

Der Datenpointer des Objekts kann mit ObjGetDataPtr abgerufen und mit ObjSetDataPtr gesetzt werden. Wenn ClassObj eine Strukturklasse ist, kann der Datenpointer auch mit Obj.Ptr abgerufen werden.

Beispiele

Erstellt einen referenzgezählten Rückruf.

#Requires AutoHotkey v2.1-alpha.36

myCallback := CCallback(() => MsgBox("Rückruf wurde aufgerufen"))

; Rückruf kann einem Pointerfeld zugewiesen werden.
sample := SampleStruct()
sample.callback := myCallback

; Nur um zu zeigen, dass wir diese Referenz nicht behalten müssen:
myCallback := unset

; Rückruf aufrufen (besser wäre es, ihn via Struktur an eine API zu übergeben).
DllCall(NumGet(sample, IntPtr))

sample := unset
MsgBox "Variablen wurden ungesetzt gemacht"

struct SampleStruct {
    callback : CCallback.Ptr
}

struct CCallback {
    static Call(args*) {
        cb := CallbackCreate(args*)
        MsgBox "Erstelle Rückruf " cb
        return ObjCreateWithDataPtr(this, cb)
    }
    __delete() {
        MsgBox "Lösche Rückruf " this.ptr
        CallbackFree(this.ptr)
    }
}
