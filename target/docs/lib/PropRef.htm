PropRef [v2.1-alpha.10+]

Erstellt eine virtuelle Referenz, die auf eine Eigenschaft eines Objekts verweist.

Ref := PropRef(Obj, Name)

PropRef selbst ist eine Klasse, die von Any abgeleitet ist.

Parameter

Obj

Typ: Objekt oder ComValue

Beliebiges Objekt.

Name

Typ: Zeichenkette

Der Name der Eigenschaft.

Rückgabewert

Typ: PropRef

Diese Funktion gibt eine virtuelle Referenz zurück, die auf die Eigenschaft verweist – also ein Objekt mit einer __Value-Eigenschaft zum Abrufen oder Setzen des Wertes der Zieleigenschaft. Diese Referenz kann an einen ByRef-Parameter übergeben werden.

Bemerkungen

In den meisten Fällen sollte man diese Klasse nicht direkt verwenden. Besser ist es, den Referenzoperator zu verwenden, um eine Referenz auf eine Eigenschaft abzurufen (über die __Ref-Methode).

Allerdings kann diese Funktion auch mit ComValue und abgeleiteten Typen verwendet werden, oder um eine benutzerdefinierte __Ref-Implementierung zu umgehen.
