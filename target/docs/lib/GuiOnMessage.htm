OnMessage (GUI) [v2.1-alpha.1+]

Registriert eine Funktion oder Methode, die aufgerufen wird, wenn das GUI-Fenster oder -Steuerelement eine bestimmte Meldung empfängt.

Gui.OnMessage(MldNummer, Rückruf , HinzufügenEntfernen)
GuiCtrl.OnMessage(MldNummer, Rückruf , HinzufügenEntfernen) ; Benötigt [v2.1-alpha.7+]

Parameter

MldNummer

Typ: Integer

Die Nummer einer Meldung, die überwacht werden soll.

Rückruf

Typ: Zeichenkette oder Funktionsobjekt

Eine Funktion, eine Methode oder ein Objekt, die/das aufgerufen wird, wenn die Meldung empfangen wurde.

Wenn die GUI ein Event-Sink hat (d.h. wenn der EreignisObj-Parameter von Gui() angegeben wurde), kann dieser Parameter der Name einer Methode im Event-Sink sein. Andernfalls muss dieser Parameter ein Funktionsobjekt sein.

Die Rückruffunktion akzeptiert vier Parameter und kann wie folgt definiert werden:

MeinRückruf(GuiOderCtrlObj, wParam, lParam, Mld) { ...

Es spielt keine Rolle, welche Namen Sie den Parametern geben, allerdings werden ihnen die folgenden Werte nacheinander zugewiesen:

  1. Das Gui- oder GuiControl-Objekt des GUI-Fensters bzw. -Steuerelements, das die Meldung empfangen hat.
  2. Der WPARAM-Wert der Meldung.
  3. Der LPARAM-Wert der Meldung.
  4. Die Meldungsnummer (nützlich, wenn eine Rückruffunktion mehr als eine Meldung überwacht).

Es können beliebig viele Parameter am Ende der Parameterliste der Rückruffunktion weggelassen werden, wenn die entsprechenden Informationen nicht benötigt werden, aber dann muss als letzter Parameter ein Sternchen angegeben werden, z.B. MeinRückruf(Param1, *).

Beachten Sie jedoch die Hinweise bei OnEvent – insbesondere in Bezug auf this und den GuiOderCtrlObj-Parameter.

Wenn der Rückruf einen nicht-leeren Wert zurückgibt, führt das dazu, dass 1) dieser als Antwort für die Meldung verwendet wird, 2) alle weiteren Rückrufe nicht aufgerufen werden und 3) die reguläre Meldungsverarbeitung durch das GUI-Fenster unterdrückt wird.

Der Rückruf sollte entweder einen Integer oder eine leere Zeichenkette zurückgeben oder keinen expliziten Rückgabewert liefern.

HinzufügenEntfernen

Typ: Integer

Wenn weggelassen, wird standardmäßig 1 verwendet. Andernfalls geben Sie eine der folgenden Zahlen an:

  • 1 = Die Rückruffunktion nach anderen zuvor registrierten Rückruffunktionen aufrufen.
  • -1 = Die Rückruffunktion vor anderen zuvor registrierten Rückruffunktionen aufrufen.
  • 0 = Die Rückruffunktion nicht aufrufen.

Bemerkungen

Folgende OnEvent-Hinweise gelten auch für OnMessage: Threads, GUI zerstören.

[v2.1-alpha.7+]: Wenn der Rückruf aufgerufen wird, werden A_EventInfo und das zuletzt gefundene Fenster gemäß Zusätzliche Infos für die Rückruffunktion gesetzt.

GUI-spezifische Meldungsrückrufe werden nach den globalen Meldungsrückrufen (die mit der OnMessage-Funktion registriert wurden) aufgerufen, jedoch bevor die reguläre Verarbeitung des GUI-Fensters selbst startet.

Die Rückruffunktion kann rekursiv aufgerufen werden, wenn die Meldung empfangen wird, während der Rückruf bereits ausgeführt wird. Die Anzahl der startbaren Threads wird ausschließlich durch #MaxThreads begrenzt.

[v2.1-alpha.7+]: Für GuiCtrl.OnMessage wird Fenster-Subclassing verwendet, um Meldungen zu erkennen oder abzufangen, die direkt an das Steuerelement gesendet werden. Diese Meldungen werden von der globalen OnMessage-Funktion nicht erkannt.
