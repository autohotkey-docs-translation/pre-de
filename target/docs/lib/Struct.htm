Struct [v2.1-alpha.22+]

class Struct extends Any

Struct ist die Basisklasse für alle Strukturen.

Im Gegensatz zu Object sind die Eigenschaften einer Struktur auf die Eigenschaften ihres Basisobjekts (Prototyp der Klasse der Struktur) beschränkt. In der Regel sind das typisierte Eigenschaften, die in einer Strukturdefinition deklariert sind, können aber auch dynamische Eigenschaften, Methoden und schreibgeschützte Werteigenschaften sein.

"Obj" wird hier stellvertretend für eine beliebige Instanz der Struct-Klasse verwendet.

Instanzen von Struct basieren indirekt auf Struct.Prototype, das wiederum auf Any.Prototype basiert. Zusätzlich zu den von Any geerbten Methoden und Eigenschaften haben Structs die folgenden vordefinierten Methoden und Eigenschaften.

Inhaltsverzeichnis

  • Statische Methoden:
    • Call: Erstellt ein neues Struct.
    • At: Erstellt einen gekapselten Pointer.
  • Statische Eigenschaften:
    • Prototype: Liefert den Prototyp, auf dem alle Instanzen der Strukturklasse basieren.
    • Ptr: Liefert eine Klasse, die einen Pointer auf eine Struktur dieser Klasse repräsentiert.
    • __Item: Liefert eine Klasse, die ein Array fester Größe mit dieser Klasse als Elementtyp repräsentiert.
  • Methoden:
    • __Ref: Ermittelt eine verschachtelte Struktur oder eine virtuelle Referenz, die auf eine Eigenschaft verweist.
  • Eigenschaften:
    • Ptr: Liefert die Adresse der Struktur.
    • Size: Liefert die Größe der Struktur in Bytes.

Statische Methoden

Call

Erstellt ein neues Struct.

Obj := StructKlasse()
Obj := StructKlasse.Call()

StructKlasse muss eine Unterklasse von Struct sein. Unterklassen können mithilfe einer Strukturdefinition oder während der Skriptausführung erstellt werden.

At

Erstellt einen gekapselten Pointer, der sich wie eine Instanz von StructKlasse verhält.

Obj := StructKlasse.At(Adresse)

Parameter

Adresse

Typ: Integer

Die Adresse einer Struktur des durch StructKlasse definierten Typs.

Rückgabewert

Typ: Objekt

Bemerkungen

StructKlasse muss eine Unterklasse von Struct sein.

Weitere Informationen finden Sie unter Gekapselter Pointer.

Statische Eigenschaften

Prototype

Liefert den Prototyp, auf dem alle Instanzen der Strukturklasse basieren.

Proto := ClassObj.Prototype

Weitere Informationen finden Sie unter ClassObj.Prototype.

Ptr

Liefert eine Klasse, die einen Pointer auf eine StructKlasse repräsentiert.

PtrKlasse := StructKlasse.Ptr

Typ: Klasse

Dies wird in Verbindung mit DllCall und typisierten Eigenschaften verwendet.

Weitere Informationen finden Sie unter Pointer auf Strukturen.

__Item [v2.1-alpha.23+]

Liefert eine Klasse, die ein Array fester Größe bestehend aus StructKlasse-Elementen repräsentiert.

ArrayKlasse := StructKlasse[Länge]
ArrayKlasse := StructKlasse.__Item[Länge]

Parameter

Name

Typ: Integer

Die Länge des Array-Typs.

Rückgabewert

Typ: Klasse

Der Rückgabewert ist eine Unterklasse von Struct.Array.

Dies wird üblicherweise in Verbindung mit DllCall und typisierten Eigenschaften verwendet.

Methoden

__Ref

Ermittelt eine verschachtelte Struktur oder eine virtuelle Referenz, die auf eine Eigenschaft verweist.

Obj.__Ref(Name)

Parameter

Name

Typ: Zeichenkette

Der Name der Eigenschaft.

Rückgabewert

Typ: Objekt

Handelt es sich bei der Eigenschaft um eine verschachtelte Struktur, wird eine Referenz zurückgegeben, die auf diese Struktur verweist. Der Eigenschaft, die einer verschachtelten Struktur entspricht, kann nur ein Wert zugewiesen werden, wenn die Struktur eine setzbare __Value-Eigenschaft definiert. In diesem Fall kann die Struktur selbst auch als virtuelle Referenz verwendet werden. Da ein abstrakter Datentyp in der Regel sowohl einen Getter als auch einen Setter implementiert, kann die verschachtelte Struktur selbst nur über diese Methode abgerufen werden.

Handelt es sich bei der Eigenschaft um einen Pointertyp oder nicht um eine verschachtelte Struktur, wird eine PropRef erstellt und zurückgegeben.

Bemerkungen

Diese Methode wird normalerweise indirekt über den Referenzoperator aufgerufen. Zum Beispiel ist &Obj.Prop dasselbe wie Obj.__Ref('Prop').

Anstelle einer Variablenreferenz kann eine virtuelle Referenz an einen ByRef-Parameter übergeben werden.

Eigenschaften

Ptr

Liefert die Adresse der Struktur.

Adresse := Obj.Ptr

Typ: Integer

Die Adresse einer Struktur ist identisch zur Adresse ihres ersten Feldes (typisiertes Feld).

Size

Liefert die Größe der Struktur in Bytes.

Größe := Obj.Size

Typ: Integer
